# 🌐 First Webpage Using HTML

This repository contains my very first webpage project created using only HTML during my 12th-grade holidays as I began learning web development.

I used this project to practice and apply everything I learned while exploring the fundamentals of web development, including:
- Basic webpage structure
- Navigation between pages
- Images and content layout
- Forms and HTML elements

## 📂 Project Structure

All project files are placed inside the same folder, including:
- `Main.html` → Main webpage file
- `fullstack.html`
- `Resigiration.html`
- `image/` → Contains all project images

▶️ Open `Main.html` to view the main webpage.

This project marks the beginning of my journey into the tech field and serves as a strong first step toward becoming a full-stack developer.
